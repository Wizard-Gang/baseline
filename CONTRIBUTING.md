# Contributing

[AGENTS.md](AGENTS.md) is the delivery contract for people and agents alike: the work queue, plan edits and IDs, release branches, CI-only testing, review and merge. Every Wizard-Gang repository carries it and this file byte for byte from `Wizard-Gang/baseline`, and changes them there first.

[README.md](README.md) and the documents it links hold this repository's product, commands, required checks, invariants, ID namespace and release or deployment boundaries. `docs/CHANGE-MANAGEMENT.md` holds its commit and PR format. Read [SECURITY.md](SECURITY.md) before reporting a vulnerability.

Agent session cost and the owner's hooks are governed by the owner rulebook, `agent/RULEBOOK.md` in `Wizard-Gang/baseline`.
