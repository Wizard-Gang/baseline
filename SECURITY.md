# Security policy

Report a vulnerability privately using GitHub's **Report a vulnerability** entry in the repository Security tab, when enabled. If that feature is unavailable, contact the repository owner through a private channel. Do not put exploit details or credentials in a public issue or pull request.

This seed runs no service itself. `platform/wg-edge/` is shared Worker code that consuming repositories vendor and deploy, so its host guard, operator gate, response headers, error redaction, logs and app-scoped storage helpers are part of this repository's security surface; changes to it are `SEC` or `FEAT` changes with tests that keep each control fail-closed. Its only operator credential is `WG_OPS_TOKEN`, read at runtime. The rest of the security surface is the dependency graph, GitHub Actions, repository permissions, merge controls, tag and Release identity, and published artifacts. CI uses read-only permissions except the bounded release publication job. Actions are pinned to full commit SHAs. Dependency and workflow update suggestions are inputs to a controlled `SEC` or `BUILD` change; they do not bypass IDs, review, or exact-head CI.

`npm audit --audit-level=high` is a network-backed required check. Dependency and GitHub Actions updates follow the controlled queue. A vulnerable dependency is updated or explicitly removed in a controlled change. Do not add an audit bypass, ignore rule, or broader token scope without a specific risk record and owner review. Keep tokens in environment or GitHub secrets, never in source, PR text, test fixtures, or logs. The Cloudflare deploy token lives only in the `production` environment of each repository declared in `config/cloudflare.json`. The owner rotates it with `npm run rotate:cloudflare-token -- --apply`, which takes the value from piped stdin, hands it to `gh secret set` over stdin and never places it in an argument, the environment or the output. A repository-level copy is drift: it is never refreshed, and the owner deletes it from [the Cloudflare runbook](docs/CLOUDFLARE-RUNBOOK.md) once the repository's production environment holds the token.
